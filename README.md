# ⚔️ Битва — Telegram Mini App

Боевой кликер: атакуй врагов, качай снаряжение. Сделан как [Telegram Mini App](https://core.telegram.org/bots/webapps) на чистом HTML/CSS/JavaScript — **без сборки и зависимостей**.

## 🎮 Механика

- Удар по врагу (**⚔️**) тратит **стамину** (−10) и имеет **перезарядку** (0.6 сек)
- Урон за удар = **мощность**; есть шанс крита ×3
- Побеждаешь врага → получаешь золото → приходит следующий, сильнее (+35% HP)
- Врагов 8 видов (от крысы до дракона), потом цикл повторяется
- Магазин снаряжения:

  | Улучшение | Эффект |
  |---|---|
  | 🗡 Острый клинок | +1 к урону |
  | 💪 Выносливость | +10 макс. стамины, +0.5/сек реген |
  | 🔄 Перезарядка | −8% к времени перезарядки (до 15 ур.) |
  | 🤖 Наёмник | +1 урона/сек автоматически |
  | 💥 Критический удар | +3% шанс крита ×3 (до 12 ур.) |

- Прогресс сохраняется в `localStorage` браузера/Telegram

### 💾 Сохранения
- **Отдельный прогресс у каждого пользователя** — ключ сохранения привязан к Telegram `user.id`, поэтому несколько аккаунтов на одном устройстве не конфликтуют
- **Автосохранение при выходе** (сворачивание/закрытие мини-аппа) и после каждого клика/покупки
- **Загрузка при входе** — прогресс восстанавливается автоматически
- **Telegram CloudStorage** — облачное хранилище Telegram (если запущено как Mini App): прогресс синхронизируется между устройствами одного аккаунта; берётся сейв с наибольшим количеством монет
- Вне Telegram сохранения работают через `localStorage`
- Автоматическая миграция старых общих сохранений в персональные

## 🚀 Деплой на GitHub Pages

1. Создай репозиторий на GitHub и запушь этот проект:
   ```bash
   git init
   git add .
   git commit -m "Кликер: Telegram Mini App"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```
2. В репозитории открой **Settings → Pages**.
3. В разделе **Source** выбери: `Deploy from a branch` → ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу:
   ```
   https://<username>.github.io/<repo>/
   ```

## 🤖 Подключение к Telegram-боту

1. Открой [@BotFather](https://t.me/BotFather) в Telegram.
2. Создай бота: `/newbot` (если ещё нет) — сохрани токен.
3. Настрой Mini App: `/newapp` или **Bot Settings → Menu Button → Configure menu button** → отправь ссылку:
   ```
   https://<username>.github.io/<repo>/
   ```
4. Также можно добавить кнопку запуска: **Bot Settings → Menu Button → Enable**.
5. Открой бота и нажми кнопку меню — игра запустится как Mini App. 🎉

## 🛠 Локальный запуск

Просто открой `index.html` в браузере, либо запусти любой статический сервер:

```bash
# Python
python -m http.server 8080

# или Node.js
npx serve .
```

Открой `http://localhost:8080` — вне Telegram игра работает в обычном браузере (вибрация и тема Telegram просто отключены).
